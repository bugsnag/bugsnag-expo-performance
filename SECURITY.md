# Security Policy

## Supported Versions

Support for the BugSnag package matches the policy of the Expo SDK: ~6 months of backwards compatibility, spanning approximately 3 major releases. For simplicity, the versioning of our package aligns with the version of the Expo SDK that it supports.

## Reporting a Vulnerability

If you find a vulnerability in this SDK, please report it to our [Security Team](mailto:security@smartbear.com) for review.
